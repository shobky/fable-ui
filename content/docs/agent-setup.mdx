## Agent skill

For agents that support skills, this repository ships one at `.agents/skills/fable-ui`. It contains the same procedures, the block catalog, and a `doctor` script that checks an app's setup (Tailwind v4, shadcn, aliases, AI SDK version, the route, the font token).

Install it into your project:

```bash
npx skills add shobky/fable-ui --skill fable-ui
```

Or download [`fable-ui.skill`](/skills/fable-ui.skill) and unzip it into your agent's skills folder.

## What a good result looks like

After setup, ask the chat for:

1. *"Compare three databases for a small SaaS"* — a sortable table, streamed row by row.
2. *"Help me plan a dinner party — ask what you need"* — a form; submitting it sends your answers back.
3. *"Hi!"* — plain text. Fable is for structure, not every reply.

If any of these fails, have the agent run the doctor script:

```bash
node .agents/skills/fable-ui/scripts/doctor.mjs
```
