`SuggestedActions` shows prompts the user can send next. It never calls host APIs directly.

## Tool

The AI SDK tool name is `show_next_actions`.

Use it for prompt-only follow-ups such as "Compare to yesterday" or "Show the source rows". Do not use it to perform writes, deletes, charges, sends, or status changes.

Installed files include `components/fable-ui/suggested-actions/*`, `lib/fable-ui/tools/show-next-actions-tool.ts`, the manifest, and eval guidance.
