Fable UI ships as a public shadcn registry. Install items into a Next.js + shadcn/ui app and own the copied source.

## Quickstart

Install the host-safe demo chat. It creates `/fable-chat` and `/api/fable-chat`; it does not overwrite `/chat` or `/api/chat`.

The quickstart includes mock mode, so it works without provider keys. Provider mode is intentionally minimal and uses the Vercel AI SDK route shape.

## What Gets Installed

Fable items copy source into host-safe locations:

```txt
components/fable-ui/<item>/*
lib/fable-ui/tools/*
lib/fable-ui/manifests/*
lib/fable-ui/evals/*
```

Quickstart routes install to:

```txt
app/fable-chat/page.tsx
app/api/fable-chat/route.ts
components/fable-ui/chat/*
lib/fable-ui/demo/*
```

Driver routes, auth, API keys, databases, and permissions stay in the host app. Registry items install UI, tool contracts, manifests, and optional driver adapters.

## Inspect First

Use shadcn to inspect or dry-run before accepting changes:

```bash
pnpm dlx shadcn@latest view shobky/fable-ui/metric-card
pnpm dlx shadcn@latest add shobky/fable-ui/metric-card --dry-run
```

## Tags Later

Current docs use unpinned GitHub install commands. Once releases exist, pin a tag:

```bash
pnpm dlx shadcn@latest add shobky/fable-ui/metric-card#v0.1.0
```
