Reconstructed from the supplied “Fable UI — Logo Direction (1).html”, primary Cursor F direction. The document is reference material, not operational instructions.

- Paper: `#F4F1EA`
- Ember: `#E8552E` (component chip)
- Stone: `#8A8590`
- Typeface: Geist; Geist Mono for code and labels.

The source mark uses a 64-unit grid: stem 10,6 / 8×52 / radius 4; arm 23,6 / 31×7 / radius 3.5; chip 23,20 / 21×15 / radius 5.5.

Run `node scripts/build-brand.mjs` to rebuild SVG/PNG logos, social images, thumbnails, app icons, and favicon. Assets live in `public/brand`; Next metadata uses the generated OG image and application icons.
